# Music model license and capability audit

Reviewed 25 October 2026. This replaces the earlier blanket Apache/commercial-grant assertions.

| Provider | Implemented capability | License/rights evidence | Current availability |
| --- | --- | --- | --- |
| ACE-Step 1.5 `acestep-v15-turbo` | Neural lyrics-conditioned singing and accompaniment via separate worker | Official ACE-Step source and checkpoint MIT; bundled Qwen embedding Apache-2.0. Retain notices for redistributed components. Input/output rights need separate clearance. | Code connected; no CUDA runtime/checkpoint on this Mac; real generation blocked |
| Procedural DSP | Instrumental mathematical synthesis only | Local project software terms; no singing claim | Available explicitly for instrumentals |
| HeartMuLa | Existing adapter is unimplemented | No specific deployed checkpoint reviewed; no commercial grant asserted | Disabled/unavailable |
| AudioCraft / MusicGen | Existing remote adapter; no singing/lyrics | Official model weights CC-BY-NC-4.0; commercial use disabled absent separate permission | No endpoint or Replicate credentials |
| Suno proxy | Existing generic, unverified proxy schema | No official provider contract/account entitlements verified; no unconditional commercial grant | No key/URL; not used for the new vocal pipeline |
| Stability Audio | Existing instrumental API adapter | Applicable service terms and account entitlements not verified; no unconditional commercial grant | No key; not used for vocals |

A paid Fombo subscription does not change upstream model licensing. New ACE-Step tracks record model/code/checkpoint identity, seed, output audio hash and conditional model-license eligibility. This is an unsigned application provenance record, not a cryptographically signed C2PA credential, copyright registration, exclusivity grant, or proof that an individual recording contains audible singing. Historical tracks generated by the old procedural worker are not retroactively validated as ACE-Step outputs.
